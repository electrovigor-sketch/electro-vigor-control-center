# مرکز کنترل الکترو ویگور

PWA فارسی برای مدیریت نقشه‌راه ۱۵ استپی الکترو ویگور، ثبت اطلاعات پایه کسب‌وکار، سنجش عملکرد کانال‌ها، شاخص‌ها و اهداف، چرخه تصمیم‌گیری، محتوا، فروش، محصولات، هزینه‌ها و صدور فاکتور قابل چاپ/PDF.

## انتشار روی GitHub Pages
1. فایل‌های داخل این پوشه را در ریشه مخزن `electro-vigor-control-center` بارگذاری کن (نه خود پوشه و نه ZIP).
2. در Settings → Pages، منبع `Deploy from a branch`، شاخه `main` و پوشه `/(root)` باشد.
3. چند دقیقه صبر کن و لینک Pages را باز کن.
4. در Chrome اندروید، منوی سه‌نقطه → `Add to Home screen` یا `Install app` را بزن.

## امکانات
- ۱۵ ماژول نقشه‌راه با وضعیت، مسئول، مهلت، یادداشت، وظایف و خروجی
- داشبورد مدیریتی و ثبت دستی عملکرد کانال‌ها
- شاخص‌ها و اهداف و چرخه ثبت تصمیم/آزمایش/یادگیری
- فهرست فروش، محصولات، محتوا و هزینه‌ها
- فاکتور مشتری با ردیف کالا، تعداد، قیمت، تخفیف، پرداخت و مانده؛ چاپ یا ذخیره به PDF از پنجره چاپ مرورگر
- پشتیبان‌گیری و بازیابی JSON و خروجی CSV فروش
- لوگوی رسمی کاربر در برنامه و آیکون نصب با نماد EV

## محدودیت‌های مهم
- داده‌ها در `localStorage` همان مرورگر و دستگاه ذخیره می‌شوند؛ همگام‌سازی ابری، حساب کاربری و اتصال خودکار به WooCommerce/ترب/شبکه‌های اجتماعی در این نسخه فعال نیست.
- فاکتور ابزار ثبت و چاپ است و به‌خودی‌خود صورتحساب الکترونیکی رسمی یا اتصال سامانه مؤدیان محسوب نمی‌شود. قوانین مالیاتی و جزئیات حقوقی را جداگانه بررسی کن.
- قبل از پاک‌کردن داده‌های مرورگر، از بخش پشتیبان‌گیری فایل JSON بگیر.
